## **General**
Two additional instance generators for the Google Hashcode 2016 Problem:
- **"Deja Vu":** Provide large instance with high duplicity and random noise.
- **"Universal Lambda":** Provide variable instance with no explicit duplicity. Hand most of the instance creation to the user itself through external functions. Hence, it is the most opened generator, while not warranting any creation of *valid* instances.

For *Deja Vu*, the instance is always valid as long as the $1.1\cdot\frac{R}{E}\le \text{MaxAuthorisedRequestPerEndpoint}$, which is set, by default, to 10 000. Additionally, put some security margin for the number of request as this method can create slightly more request than requested (if you ask for 1M, you may go out of authorised bound).

Concerning *Universal Lambda*, no warranty are provided concerning the instance validity as the generation of video sizes, caches connection, data center latency, and requests are all on the user. The number of request is not asked by the generator because it is infered by the set of requests generated by the user.

## **Validation of an instance**
To test the validity of an instance, you can execute the `instanceValidator.py` file using `python .\instanceValidator`, then copy pasting your instance (you may have to press *enter* at some point in the process*. Notice that you will need `instanceCrator.py` as dependency in the same file since limitations are set up there.

The validator check for the following:
- assert 1 <= V <= ic.MAX_AUTHORISED_VIDEO_NUMBER (10 000), "Maximum number of video exceeded or negative."
- assert 1 <= E <= ic.MAX_AUTHORISED_ENDPOINT_NUMBER (1000), "Maximum number of endpoint exceeded or negative."
- assert 1 <= R <= ic.MAX_AUTHORISED_REQUEST_NUMBER (1 000 000), "Maximum number of requests exceeded or negative."
- assert 1 <= C <= ic.MAX_AUTHORISED_CACHE_NUMBER (1000), "Maximum number of cache exceeded or negative"
- assert 1 <= X <= ic.MAX_AUTHORISED_CACHE_CAPACITY (500 000), "Maximum cache capacity exceeded or negative"
- assert 1 <= v <= ic.MAX_AUTHORISED_VIDEO_SIZE (1000), "Maximum video size exceeded or negative"
- assert ic.MIN_AUTHORISED_SERVER_LATENCY (2) <= latency_dc <= ic.MAX_AUTHORISED_SERVER_LATENCY (4000), "Maximum or Minimum Data Center Latency not respected."
- assert 1 <= latency <= ic.MAX_AUTHORISED_CACHE_LATENCY (500), "Maximum cache latency exceeded or negative"
- assert latency < latency_dc, "Cache Latency greater or equal to local server latency."
- requestsPerEndpoint[endpoint] <= ic.MAX_AUTHORISED_REQUEST_PER_ENDPOINT (10 000), "Maximum number of request per endpoint exceeded"

If the instance a valid, you will get a confirmation. Otherwise, one of the above error message will show.

## **How to use**
In `instanceCreator.py`, select your generator, modify the kwargs as you wish, run. **CHECK YOUR INSTANCE WITH THE VALIDATOR**
